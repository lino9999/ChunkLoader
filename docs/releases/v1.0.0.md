# ChunkLoader 1.0.0

The first public release of ChunkLoader by Lino: timed and infinite chunk loaders for Paper, with inventory menus, XP and optional Vault refueling, native holograms, chunk borders, and offline farm operation.

## Download and install

Download **ChunkLoader-1.0.0.jar** from the assets below, place it in your server's `plugins` directory, and restart. The `.sha256` asset lets you verify the download.

- **Paper:** 1.21.11 through 26.3.
- **Java:** 21 for Minecraft 1.21.11; 25 for Minecraft 26.x.
- **Optional dependency:** Vault and an economy provider for money purchases.
- **First command:** `/chunkloader give YourName 2h`.
- **Aliases:** `/cl` and `/cloader`; permission nodes use `chunkloader.*`.

Paper is required. Spigot-only servers and Folia are outside the supported platform. Set `pause-when-empty-seconds=-1` in `server.properties` for operation while no players are connected.

## Included features

- One loaded chunk per placement, with independent timed or infinite fuel.
- Refueling through XP levels, money, or another loader item.
- Owner access, administrator controls, player limits, and world restrictions.
- Native floating text, private border particles, and paginated loader lists.
- Shared chunk tickets, block protection, validated JSON, and atomic backups.
- Bounded inactive-spawner simulation without duplicate native crop ticks.

## Verification and scope

The application classes in this release are byte-for-byte identical to the implementation that passed 56 unit tests and 108 runtime assertions on Paper 1.21.11/132, 26.1.2/74, 26.2/134, and 26.3/218. Runtime checks included zero-player crops, furnaces, hoppers, custom spawner snapshots, cancellation events, overlapping loaders, expiration, and restart persistence.

Test sources, dependencies, generated reports, and disposable servers were subsequently removed at the owner's request. Current CI builds the production plugin on Java 21 and Java 25.

Custom species-specific spawn rules, equipment-table behavior, and exact spawner event nesting can differ from native Minecraft behavior. Existing plugin databases and legacy items are not imported automatically.
