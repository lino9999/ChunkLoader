# ChunkLoader 1.0.1

Maintenance release by Lino, focused on loader lifecycle correctness and bounded server work.

## Fixes

- Register placements immediately and discard canceled placement metadata without deleting restored blocks or issuing duplicate refunds.
- Account for each loader's actual active ticks, including new placements in already-loaded chunks, item returns, refueling, save snapshots, and world unloading.
- Prevent expired or physically missing loaders from accepting fuel, and calculate access from registered ownership.
- Preserve newer chunk requests when an old world finishes loading. Deduplicate the queue, bound unfinished requests and queue scans, and delay failed retries by 200 ticks.
- Drain background writes without worker-thread Bukkit callbacks. Propagate final-save failures and continue cleaning up other components when one fails.
- Handle expired persisted records, malformed item tag types, off-hand interactions, TNT priming, and unsupported multi-block placements safely.
- Reject fractional, overflowing, or incorrectly typed configuration values instead of silently coercing them.
- Dispatch cancellable spawner events for non-living entities too, prevent recursive event dispatch, and update spawner states without neighbor physics.
- Avoid extra active-chunk snapshot copies and repeated spawn-rule lookups. Drop simulation backlog when disabled and preserve elapsed time when its interval changes.

## Requirements

Paper 1.21.11 through 26.3. Use Java 21 for Minecraft 1.21.11 or Java 25 for Minecraft 26.x. Vault and an economy provider remain optional.

Stop the server, back up its worlds and `plugins/ChunkLoader` folder, replace the JAR, and restart. The data schema, commands, permission nodes, and default configuration keys are unchanged.

See the [maintenance audit](https://github.com/lino9999/ChunkLoader/blob/main/docs/AUDIT-1.0.1.md) for verification evidence and the [compatibility guide](https://github.com/lino9999/ChunkLoader/blob/main/docs/COMPATIBILITY.md) for supported behavior and existing spawner boundaries.
